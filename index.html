Deployment Architecture: Each subscription gets 1 Key Vault (stores API credentials) and network infrastructure in each enabled region. Scanner VMs are created temporarily during scans and automatically deleted after completion.

Cost Averaging: VM costs represent actual scan hours. For quarterly scans, costs are averaged monthly for budgeting (e.g., 1 scan every 3 months = 1/3 of the scan cost per month on average).

Note: Key Vault costs are negligible (transaction-based). Major costs are Private Endpoint and NAT Gateway (24/7 always-on resources, billed at 730 hrs/month). Data transfer costs are minimal because scanners only upload metadata, and all data reading happens within the same region (free intra-region transfer).

💡 Cost Optimization Tips

  • Remove NAT Gateway to save ~70% on infrastructure costs (see network configuration options)
  • Without NAT Gateway: Scanner VMs use temporary public IPs during scans only (minimal cost)
  • With NAT Gateway: Provides shared static IP for all scanners (higher cost but centralized)
  • Adjust scan frequency based on your compliance requirements (quarterly is default)
  • Limit scanning to specific regions where sensitive data resides
  • Consolidate subscriptions when possible - each adds infrastructure overhead

📡 Data Transfer Cost Breakdown

Why data transfer costs are minimal:

  • No cross-region data movement: Scanner VMs are deployed in the same region as your data
  • Intra-region transfers are FREE: Scanner reads Azure Blob Storage containers locally (no Azure egress charges)
  • Only metadata uploaded: DSPM sends scan findings/classifications to CrowdStrike, not the actual data being scanned (~0.5 GB per scan)
  • Outbound internet costs: ~$0.087/GB for first 100 GB/month (metadata upload)
  • NAT Gateway data processing: ~$0.045/GB if NAT Gateway is enabled

Example: 30 subscriptions × 1 region × quarterly scans (1 scan/quarter = 0.33/month) = 10 scans/month × 0.5 GB = 5 GB/month = ~$0.44 outbound + ~$0.23 NAT processing = ~$0.67/month total data transfer cost

Compared to infrastructure costs (NAT Gateway alone = $986/month for 30 regions), data transfer is negligible.

About DSPM Cost Estimation

📖 How DSPM Costs Work

Performing DSPM scans results in a slight increase in cloud consumption costs. The exact amount varies based on the size of the environment and Azure's pricing structure.

Resources provisioned by CrowdStrike DSPM:

  • Per Subscription: Azure Key Vault (1 per subscription, stores API credentials)
  • Per Subscription Per Region: Virtual Network, Private Endpoint, NAT Gateway (optional), Public IP (if NAT Gateway enabled) - Each subscription gets isolated scanning infrastructure in each enabled region
  • At Scan Time: Azure VM Standard_F8s_v2 (temporary, auto-deleted after scan)
  • Transaction Costs: Key Vault secret operations (~$0.03/10k reads), data transfer (metadata only, no cross-region costs)

Important: Each subscription gets its own isolated scanning environment. With 10 subscriptions × 1 region, you deploy 10 separate infrastructures, not 1 shared infrastructure. This is why costs scale with subscription count.
