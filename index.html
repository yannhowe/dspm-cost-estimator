Deployment Architecture:

  • Per-account scanning: Each subscription gets its own Key Vault and network infrastructure in each enabled region. Scanner VMs are created temporarily during scans and automatically deleted after completion.
  • Cross-account scanning (NEW - April 2026): Scanner infrastructure is deployed only to a designated host subscription. The data scanner scans storage in other subscriptions remotely. Key Vaults are still deployed per subscription.
  • Use your own VNet (NEW - April 2026): For cross-account mode, you can bring an existing VNet instead of CrowdStrike provisioning VNet/NAT/Public IP/NSG, further reducing costs.

Cost Averaging: VM costs represent actual scan hours. For quarterly scans, costs are averaged monthly for budgeting (e.g., 1 scan every 3 months = 1/3 of the scan cost per month on average).

Note: Key Vault costs are negligible (transaction-based). Major costs are Private Endpoint and NAT Gateway (24/7 always-on resources, billed at 730 hrs/month). Data transfer costs are minimal because scanners only upload metadata, and all data reading happens within the same region (free intra-region transfer).

Cost Optimization

  • Use Cross-account scanning to deploy infrastructure only on a single host subscription — dramatically reduces always-on costs for multi-subscription environments
  • Bring your own VNet (cross-account mode) to skip VNet/NAT Gateway/Public IP/NSG provisioning entirely
  • Remove NAT Gateway to save ~70% on infrastructure costs (see network configuration options)
  • Without NAT Gateway: Scanner VMs use temporary public IPs during scans only (minimal cost)
  • With NAT Gateway: Provides shared static IP for all scanners (higher cost but centralized)
  • Adjust scan frequency based on your compliance requirements (quarterly is default)
  • Limit scanning to specific regions where sensitive data resides

Data Transfer Details

Why data transfer costs are minimal:

  • No cross-region data movement: Scanner VMs are deployed in the same region as your data
  • Intra-region transfers are FREE: Scanner reads Azure Blob Storage containers locally (no Azure egress charges)
  • Only metadata uploaded: DSPM sends scan findings/classifications to CrowdStrike, not the actual data being scanned (~0.5 GB per scan)
  • Outbound internet costs: ~$0.087/GB for first 100 GB/month (metadata upload)
  • NAT Gateway data processing: ~$0.045/GB if NAT Gateway is enabled

Example: 30 subscriptions × 1 region × quarterly scans (1 scan/quarter = 0.33/month) = 10 scans/month × 0.5 GB = 5 GB/month = ~$0.44 outbound + ~$0.23 NAT processing = ~$0.67/month total data transfer cost

Compared to infrastructure costs (NAT Gateway alone = $986/month for 30 regions), data transfer is negligible.

About Azure Cloud Security Cost Estimation

How Costs Work — New Registration Architecture (Bicep/Terraform)

When you register Azure subscriptions with CrowdStrike using the new registration methods (Bicep or Terraform), the following resources are created. This replaces the legacy architecture that used Azure Functions, Storage Accounts, and App Service Plans.

1. IOMs (Indicators of Misconfiguration) — Free

  • RBAC custom role (Reader-equivalent) per subscription or management group
  • Enterprise Application in Entra ID
  • Cost: $0/month — no billable Azure resources

2. Real-time Visibility & Detection (IoA) — Shared Infrastructure

  • EventHub Namespace: 1 namespace in the CrowdStrike infrastructure subscription (~$11/month base)
  • EventHubs: 2 event hubs (Entra ID logs + Activity logs) — included in namespace
  • Throughput Units: Configurable (default 2 TU, ~$11/month each)
  • Diagnostic Settings: Per subscription + Entra ID (free)
  • Enterprise Application: Azure Event Hubs Data Receiver role (free)

Key change from legacy: CrowdStrike now pulls logs directly from EventHub instead of Azure Functions forwarding to CrowdStrike via API. This eliminates Functions, Storage Accounts, VNet, Key Vault, Private Endpoints, App Service Plans and their associated costs from the base registration. Those resource types now only appear if DSPM is enabled.

3. DSPM (Data Security Posture Management) — Per Subscription + Per Region

  • Per Subscription: Azure Key Vault (stores API credentials), RBAC role definitions & assignments
  • Per Host Subscription Per Region: Virtual Network, Private Endpoint, NAT Gateway (optional), Public IP (if NAT Gateway). In per-account mode, every subscription is a host. In cross-account mode, only the designated host subscription.
  • At Scan Time (temporary): Azure VM Standard_F8s_v2, OS Disk, NIC, NSG — auto-deleted after scan
  • Transaction Costs: Key Vault secret operations (~$0.03/10k reads), data transfer (metadata only)

DSPM Scanning Modes (April 2026+):

  • Per-account: Infrastructure in every subscription × region. Full isolation per subscription.
  • Cross-account (NEW): Infrastructure only in host subscription × region. Scanner reaches into other subscriptions. 90%+ infra cost reduction for multi-sub environments.
  • Use your own VNet (NEW): Skip VNet/NAT/PIP/NSG provisioning entirely (cross-account only).
